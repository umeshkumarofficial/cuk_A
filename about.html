About BookHub

A simple place for curious minds and book lovers.

Books make every journey bigger.

BookHub is a student-built online bookstore concept created to make discovering books simple and enjoyable. Browse different categories, search for titles, add books to your cart and see your total instantly.

The project is built using HTML, CSS and vanilla JavaScript. It uses browser local storage for the demo cart and account experience, so no backend or real payment system is connected.
